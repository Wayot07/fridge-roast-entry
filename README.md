A [make.fun](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) entry for **Fridge Roast: One Line, Biggest Laugh** — a program that writes a single original line roasting a smart fridge (its camera, its screen, its ads) to `/output/entry.txt`.

The roast:

> My $3,000 smart fridge photographs my leftovers, then shows me ads for the food I already own.

## Run

Requires Node 22.18+ (uses Node's built-in TypeScript support, stdlib only):

```sh
node main.ts
```

It writes the line to `/output/entry.txt` — one line, 94 characters, no trailing newline — and validates the 1–200 character gate before writing.
